### Actions (`App\Actions\Projects`, frozen §6 signatures)
```php
final class SaveProject  { public function handle(?Project $existing, array $data, User $actor): Project }
final class CloseProject { public function handle(Project $project): void }
final class RestoreProject { public function handle(Project $project): ProjectStatus }
```
- **`SaveProject`** `$data` (camelCase, keys map onto the form properties): `name?`, `description?`, `startDate?`, `endDate?`, `targetBeneficiaries?`, `targetMen?`, `targetWomen?`, `targetBoys?`, `targetGirls?`, `centerId`, `programId`, `userId`.
  - Authorizes `create` / `update` for `$actor`. The status is never an input.
  - One transaction. **Program row locked first**, then the project row (lock order program → project).
  - Create always writes `draft`.
  - `startDate` / `endDate` are `prohibited` while the project is a draft (`projects.dates_prohibited_draft`). An existing draft that still holds dates keeps them untouched.
  - Approved and active projects require both dates; closed/archived accept them optionally.
  - Center required on create, and on edit when the project has one. City is the center's. Default name «{Program} — {Center}».
  - One open project per (center, program) via `Project::openProjectFor` (error on `centerId`).
  - Owner/program only change for `reassign` holders.
  - A T34 hook comment marks where `SyncProjectSectors` goes.
- **`CloseProject`**: lock row → `Gate::authorize('update')` on the locked row → refuse unless `active` (`status` error `projects.close_only_active`) → `closed`, dates kept. A second close finds `closed`, so one change is written. An owner-rejected project is refused by the policy.
- **`RestoreProject`**: `Gate::authorize('delete')` → program lock → row lock → refuse unless `archived` (`projects.only_archived_can_be_restored`) → `openProjectFor(center, program, self)` (`projects.open_project_exists`) → `closed` when both dates are set, else `draft`. Returns the new status. A project without a center skips the open-project check.
- `ChangeProjectStatus` is **deleted**, with the `changeStatus` status dropdown on the project page and `ProjectStatusChangeTest`. Owner acknowledgement before leaving draft is now T08's (`ApproveProjectFromProposal`).

### Factory states (`ProjectFactory`)
- Default: a **dateless draft** (no `start_date` / `end_date`).
- `approved()`, `active()`, `closed()`: dated. `start_date` is a plain value; `end_date` is its own closure over it, so an overridden start still gets a later end.
- `status(ProjectStatus)` is unchanged.
- Tests that need dates use a dated state by intent.
