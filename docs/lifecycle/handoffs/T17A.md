- `MonthlyReportActivityEntry`: `monthlyReport()`, `activity()` (→ `Result`).
- `ProjectActivityStatus`: `project()`, `activity()`, `monthlyReport()`.
- `Report` gains `monthlyReport()`, `lineShare()`, `isMirror(): bool` (`monthly_report_id !== null`); `Project` gains `monthlyReports()`.

**Policy** `App\Policies\MonthlyReportPolicy`: `viewAny(User)`, `view(User, MonthlyReport)`, `open(User, Project)`, `update`, `fillMealLines`, `submit`, `validate`, `return`, `requestReopen`, `decideReopen(User, MonthlyReport, MonthlyReportReopenRequest)`, `markSeen`, `delete`.
- Preparer side = `reports.create` (open) / `reports.update` (the rest) AND (`User::ownedProjectIds()` contains the project OR `SupervisionMap::supervises($user->employee_id, $ownerEmployeeId)`).
- Validator = `reports.approve` AND not General Manager AND not `prepared_by`/`submitted_by` AND (employee = `MealCoverage::responsibleFor()` OR = MEAL Manager slot holder OR (role MEAL AND `responsibleFor()` null)).
- Decider = pending request of this report AND `reports.reopen` AND not requester/preparer AND (MEAL Manager slot holder; else, only while the slot is vacant, an active Public Relations Manager).
- `delete` = never-submitted draft (`submitted_at` NULL) on the preparer side.
