### Slice 3 (CP3): workflow, mirrors, pooling

**Actions** (`App\Actions\MonthlyReports`, all `final`, resolved with `app()`)

Every action that moves state works the same way, through `App\Support\MonthlyReportGuard::lock($report, $expectedStatus, $ability, $extra = [])`:
1. One `DB::transaction`.
2. Reload the report with `lockForUpdate()`.
3. If its status ≠ `$expectedStatus`, throw `ValidationException` `status => monthly_reports.stale` and write nothing.
4. Then `Gate::authorize($ability)` on the **locked** row.

Refusals: 403 = `AuthorizationException`. A foreign id = `ModelNotFoundException`, and the whole batch is rejected.

**`SaveMonthlyReportLines` input** (T17B builds this; the server ignores every computed figure the request sends):
```php
list<array{
  id: int,                                   // monthly_report_lines.id of THIS report
  value?: ?number,                           // Count lines
  numerator?: ?number, denominator?: ?number,// FixedRatio: numerator = the count (denominator ignored); EnteredRatio: both
  not_measured?: bool,                       // EnteredRatio only
  note?: ?string,
  breakdowns?: list<array{gender: 'male'|'female', value|numerator|denominator?: ?number, disabled_value|disabled_numerator|disabled_denominator?: ?number}>, // only when the library entry is_disaggregated; replaces that scope's rows
  shares?: list<array{id: int, value?, numerator?, denominator?, not_measured?, breakdowns?}>,  // split mode only; ids of THIS line's shares
}>
```
- Entry kind is `App\Enums\MonthlyReportEntryKind::for(LibraryIndicator)`, an internal enum with no label:
  - `Count`: numeric measure.
  - `FixedRatio`: percentage with `denominator_basis = fixed`.
  - `EnteredRatio`: percentage or average with `entered` basis, or no basis.
- `shared` mode: line-level fields are copied to every share; `shares` is ignored.
- `split` mode: the per-share fields count, and line-level fields are ignored. Line totals:
  - counts: Σ of the shares;
  - ratios: Σnum ÷ Σden over the measured shares;
  - `not_measured`: true only when every share is not measured.
- A breakdown total is Σ of the rows (count 10 + 17 = 27).
- Breakdown rows: `shared` mode stores them with `monthly_report_line_share_id` NULL; `split` mode stores them per share.
- Validation errors are keyed `lines.{i}.numerator`, `lines.{i}.denominator`, `lines.{i}.shares.{j}.…` and `lines.{i}.breakdowns.{k}.disabled_*`:
  - `above_fixed_denominator` (:count);
  - `zero_denominator`;
  - `numerator_above_denominator` (percentage only);
  - `value_required` (only one of numerator/denominator given);
  - `disabled_above_gender`.
- Before any of those, a type check (`numeric`, `min:0`, `Rule::enum(Gender)`, distinct gender) runs with Laravel's default messages.

**Submit, Validate, Return and Reopen behaviour**
- **Submit**, checked in this order:
  1. `MonthlyReportPeriods::canSubmit()` (`status` key: `submit_too_early` / `submit_previous_first`).
  2. Every non-MEAL line is filled (`lines` key: `value_required`). Filled means: Count needs `value`, FixedRatio needs `numerator`, EnteredRatio needs `value` or `not_measured`. In split mode every share must be filled.

  Then it creates any missing mirror (`user_id` = the submitter), sets `submitted_at`/`submitted_by` (and `prepared_by` if empty), and moves the mirrors to `reviewed` with `submit_date` = today. The evidence check is **slice 4**.
- **Validate:** any MEAL line not filled → `lines: meal_lines_pending`. Mirrors move to `approved` and keep their `submit_date`. It records `monthly_report.validated` with properties `activity_statuses`, which is `[]` until slice 4 (`App\Support\MonthlyReportActivityStatuses::confirm()/restore()` are the hooks).
- **Return:** status → `draft`, `returned_at`/`returned_by`/`return_reason` set. Mirrors → `draft`, `submit_date` NULL.
- **Grant:** report → `draft`, `validated_at`/`validated_by` cleared. Mirrors → `draft`, `submit_date` NULL, so the figures leave `achievedValue()`. `restore()` is called (slice 4). The request → `granted`.
- **Deny:** the report stays `validated`; the request → `denied` with its note.
- **Deciders** (`App\Support\MonthlyReportDeciders::userIdsFor(MonthlyReport, int $requesterId): list<int>`) follow the same rule as the policy. With no decider, the request stays pending and `monthly_report.reopen_escalated` is recorded instead of `reopen_requested`.

**Mirrors** (`App\Support\MonthlyReportMirrors`, internal)
- `sync(report, shares, actorId, createMissing)` creates a mirror on a share's first write (`user_id` = the actor; `planned_date` = last day of M; `period_start`/`period_end` = month bounds) and updates its value/numerator/denominator after that.
- `moveTo(report, ?submitDate)` makes one bulk `update` per transition.
- Both run under `Activity::withoutRecording`: one transition = one activity.

**Generic Reports refuse mirrors.**
- `ReportPolicy::update`, `delete`, `approve` and `returnToDraft` return false when `Report::isMirror()`. `submit` follows from `update`, and `SaveReportFile` / `DeleteReportFile` authorize `update`, so they refuse mirrors too.
- When a partial select leaves `monthly_report_id` out, `isMirror()` reads it by id (one query). The Reports index and show selects now include `monthly_report_id`.

**Achievement and NULL values.** An approved NULL `reports.value` (a Not measured month) adds nothing and never becomes the latest level. This holds in both `achievedValue()` and `achievedValueSql()`. **This is a behaviour change**: a NULL could otherwise have pushed a percentage target to 0.

**Pooling** (on `App\Models\PlanIndicator`; signature agreed in plan review, Q1, as a contract addition for Dev 1 to confirm)
```php
PlanIndicator::pooledRatioSql(CarbonImmutable $from, CarbonImmutable $to): Expression          // aggregate over a plan_indicators query: Σnum ÷ Σden (×100 when percentage), null when nothing measured
PlanIndicator::pooledExcludedCountSql(CarbonImmutable $from, CarbonImmutable $to): Expression  // targets with approved rows in the window but none with a denominator
PlanIndicator::pooledRatio(iterable $targets, CarbonImmutable $from, CarbonImmutable $to): array // array{ratio: ?float, excluded: int}; needs `reports` + `indicator.libraryIndicator` loaded
```
- What it counts: approved rows with `planned_date` inside the window and `denominator > 0`.
- `fixed` basis and not cumulative: Σ numerators. Otherwise: the latest row's numerator.
- Denominator: the latest row's.
- Usage: `PlanIndicator::query()->whereKey($ids)->toBase()->selectRaw(PlanIndicator::pooledRatioSql($f, $t)->getValue(DB::connection()->getQueryGrammar()).' as ratio')`.
- The window reaches the SQL as Ymd digits only (`sqlDigits()` allowlist).
