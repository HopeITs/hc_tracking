## Migrations and commands
`2026_10_13_124015_apply_lifecycle_permission_grant_changes.php`
- **`up()`**, in one transaction:
  - detaches `targets.create/update` from General Manager and Managers;
  - attaches `funding-agreements.view/create/update` to Public Relations Manager (`syncWithoutDetaching`);
  - prints the counts, e.g. "Lifecycle permissions: N role grant(s) revoked …, M granted …". It prints only in the console, never during tests.
  - Role grants only: direct user permissions and other roles-tab edits are untouched. It is idempotent, and missing roles or permissions are skipped.
- **`down()`**: re-attaches the targets grants to GM + Managers (even if an admin had removed them before `up()`) and detaches the three funding-agreement grants from PR Manager.
- **Not run on any DB.** On local, `migrate:status` shows it Pending. Note: `2026_10_06_100000_restrict_project_creation…` is also still Pending on local.
