## How to read a proposal's current reviewers
`$proposal->reviewers()->forStage(ReviewStage::Proposal)->get()` (stage-specific; `concept_note` rows never count for `proposal`). Seen = `seen_at !== null`. People are stored as HR `employee_id`; names come from HR at read time.

## Recipients
- `ProposalRecipients::permissionExemptUserIds()` returns the reviewers' user ids for the review events, so a reviewer without module permission still gets the notification and can open the link.
- Direct recipients: `review_requested` and `reviewer_added` → the reviewer; `reviewer_seen` → project owner (immediately); oversight (MEAL / General Management) per the T21 catalog.
