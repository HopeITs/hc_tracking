  - T06 replaces this form.

  - New **Funding sources** / «مصادر التمويل» panel (`ReadsProjectFunding::fundingSources()` computed). Donor names are shown to every viewer.

- Bug fixed: `ReadsAgreementRegister` donor filter was ambiguous once `proposals.donor_id` existed. It now uses `donor_proposal.donor_id`.

## Deviations from contracts.md / the prompt
1. **The internal-donor data migration skips the insert under `runningUnitTests()`.**
   - Why: the suite migrates per test and many tests assert donor lists and counts.
   - Effect: production and local get it from the migration; tests get it from `CoreDataSeeder` (same idempotent rule, tested).
   - Dev 1 to confirm.
2. **No automated test runs the backfill migration** against pre-existing rows. DDL inside `RefreshDatabase` would break test isolation. The pre-checks were run on local data (below), but `migrate` has not yet run on the local dev DB (see Follow-ups).
3. **Tests rewritten** because their premise ("several agreements on one proposal", co-funders inside a proposal) is now impossible by design (D-24):
   - `DonorProposalTest` ("one donor may fund several proposals…", "two agreements may carry the same project number" now uses two proposals).
   - `ProposalDetailTest`: single-currency funding and climb.
   - `ProposalDetailActionsTest`: the money reading has no `others`; an agreement from the page takes the proposal's donor.
   - `FundingAgreementTest`: agreement detail no longer has a co-funder.
   - `ProposalRegisterTest`: the EUR side is a sibling "Water Response" proposal.
   - `ProposalPipelineTest`: EUR on a second "Shown" proposal; one 1,250 agreement.
   - `GanttTimelineTest`, `FundingWorkflowTest`: the donor page agreement uses the proposal's donor.
   - About 16 files gained `Proposal::query()->whereKey(...)->update(['donor_id' => …])` before an agreement factory call, so the pair matches.
   - The UI code for multi-agreement proposals (co-funder lists, `others` currencies) still exists, but it can no longer be reached. See Follow-ups.
4. `DatabaseSeederTest` donor count went from 10 to 13 (2 proposal donors + the internal donor).
