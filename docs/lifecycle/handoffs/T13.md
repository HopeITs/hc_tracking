**Table `plan_indicators`** (`2026_10_15_130213_add_unique_target_and_population_to_plan_indicators_table.php`)
- `target_population` decimal(12,2) null, after `target`.
- Unique index **`plan_indicators_source_indicator_project_unique`** (`source_type`, `source_id`, `indicator_id`, `project_id`). Rows with a NULL `project_id` are not covered (MySQL NULL semantics).

**Table `programs`** (`2026_10_15_130214_add_donor_attribution_to_programs_table.php`)
- `donor_attribution` varchar(20) NOT NULL default `shared`, after `manager_id`.

**Enum**
```php
enum App\Enums\DonorAttribution: string {
    Shared = 'shared'; Split = 'split';
    /** @param list<float> $targets */
    public function combine(array $targets): float;   // Shared → max, Split → sum, [] → 0.0
    public static function values(): array;

```
Labels `enums.donor_attribution.{shared,split}` (en, ar).

**Models**
- `Program`: `donor_attribution` fillable, cast `DonorAttribution`, `$attributes` default `shared`, activity event `donor_attribution => updated` (`program.updated`).
- `PlanIndicator`: `target_population` fillable, cast `decimal:2`; scope
  ```php
  PlanIndicator::query()->forProjectInWindow(int $projectId, CarbonImmutable $from, CarbonImmutable $to)
  ```
  = rows of that project where either `source_type = 'proposal'` and the proposal's period (actual dates when both are set, else planned) overlaps `[from, to]`, or `source_type = 'annual_plan'` and `annual_plans.year` is between `from->year` and `to->year`.

**Actions** (`app/Actions/Targets`, all `final`, all `Gate::authorize`, refusals are `ValidationException`)
```php
AttachLibraryIndicatorToResult::handle(Proposal $proposal, int $libraryIndicatorId, int $resultId): Indicator
DetachIndicatorFromResult::handle(Indicator $indicator): void
SaveProposalTargetsGrid::handle(Proposal $proposal, array $cells): array{created:int, updated:int, deleted:int}
SaveProposalTargetsGrid::versionOf(PlanIndicator $target): string   // updated_at 'Y-m-d H:i:s'
SaveProposalTargetsGrid::SourceType = 'proposal'
SetProgramDonorAttribution::handle(Program $program, DonorAttribution $attribution): Program
```
- **Attach** (`indicators.create`): proposal locked; terminal → `proposal`; result via `Result::proposalFramework($id)->whereKey()` (foreign → `ModelNotFoundException`); entry inactive → `library_indicator`; entry program not in `ProposalFramework::programIds()` and not institutional → `library_indicator` («هذا المؤشر لا يتبع برنامج هذا المقترح»); `suggested_level` set and ≠ result type → `result`; same name under the node → `library_indicator` (`already_attached`; unique-violation caught too). Copies `name` (= `name_ar`), `code`, `measure`; `frequency` = `CollectionFrequency::period()` or the column default (`quarterly`).
- **Detach** (`indicators.delete`): refused while any `plan_indicators` row exists, key `indicator`, `trans_choice('targets.detach_has_targets', n)` (Arabic plural ranges).
- **Grid** cell shape: `{indicator_id:int, project_id:int, value:?numeric, period:?Period value, target_population:?numeric, version:?string}`; `version` null = the cell was empty when loaded.
  - Gate `targets.update` up front, then per cell `targets.create` / `.update` / `.delete` (MEAL only; GM, Managers, Financial → 403).
  - Shape errors: `cells.{i}.value` (numeric, min 0, max 9999999999.99), `cells.{i}.period` (required with value, `Rule::enum(Period)`).
  - Under the proposal lock (terminal → `proposal`): foreign indicator/project → `cells.{i}` `cell_outside_proposal`; stale version → `cell_stale`; unlinked indicator → `cell_indicator_not_linked`; percentage > 100 → `percentage_over_100`; new cell with `chainIssuesFor()` issues → `cell_chain_issue`; clearing with reports → `cell_has_reports`; clearing without `targets.delete` → `cell_clear_forbidden`. Any error → whole batch refused, plus `cells` = `grid_refused`.
  - Writes: `firstOrNew` + `save` inside `Activity::withoutRecording`; unchanged cells are skipped; `target_population` defaults from `project_proposal.target_beneficiaries` on a new percentage cell.
  - **Event key:** one `proposal.targets_saved` activity on the proposal, `properties` = the counts, only when something changed (already in `EventCatalog`).

**Program page** `programs/⚡show`: a "Donors on one indicator" field (`data-program-donor-attribution`); a select for `report-templates.manage`, read-only label otherwise; `setDonorAttribution(string)`.

**Lang**: `targets.{proposal_read_only, entry_inactive, entry_outside_proposal_programs, level_incompatible, already_attached, detach_has_targets, not_linked_to_library, value_negative, value_too_large, value_numeric, percentage_over_100, period_required, period_invalid, cell_stale, cell_outside_proposal, cell_chain_issue, cell_has_reports, cell_clear_forbidden, cell_indicator_not_linked, grid_refused}`, `programs.donor_attribution{,_help,_saved}` (en, ar).
