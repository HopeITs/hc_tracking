**Routes** (`routes/web.php`, beside `reports.*`)
- `GET monthly-reports` → `pages::monthly-reports.index`, `->can('reports.view')`, name `monthly-reports.index`, `#[Title('titles.monthly_reports')]`.
- `GET monthly-reports/{monthlyReport}` → `pages::monthly-reports.show`, `->can('reports.view')`, name `monthly-reports.show`. It uses slug binding, and `mount()` runs `Gate::authorize('view', $monthlyReport)`. `#[Title('titles.monthly_report')]`.
- `GET monthly-reports/{monthlyReport}/files/{monthlyReportFile}/download` → `MonthlyReportFileDownloadController`, `->whereNumber('monthlyReportFile')->can('reports.view')->middleware('throttle:files')`, name `monthly-reports.files.download` (slice 2). The controller runs `Gate::authorize('view', $monthlyReport)`, loads the file through `$monthlyReport->files()->whereKey()` (another report's file → 404), 404s when nothing is on disk, and streams through `StoredFiles::stream()`.

**Sidebar:** "Monthly Reports" (`navigation.monthly_reports`, icon `calendar-days`) sits directly after Reports, inside the same `@can('reports.view')`, with the `monthly-reports` module badge. The NavigationTest order is now `… targets.index, reports.index, monthly-reports.index, donors.index …`.

**SubjectLinks:** `'monthly_report' => showRoute('monthly-reports.show', MonthlyReport::class, $id)`.

**List page** (`pages/monthly-reports/⚡index.blade.php`, plus `_index-mine` and `_index-validate`)
- `#[Url] tab`: `mine` or `validate`. When the user prepares no project and holds `reports.approve`, the default is `validate`; otherwise `mine`.
- **My reports** lists `ownedProjectIds()` projects plus the projects of `SupervisionMap::superviseesOf()`, one month thread per project. It takes 2 queries, and due-ness comes from `MonthlyReportPeriods::fromLoaded()`.
  - The state is derived: `upcoming` (not started), `draft`, `returned` (draft with `returned_at`), `submitted`, `validated`, `reopen_pending` (validated with a pending request).
  - The due date shows for months with lines. The overdue marker shows only on started draft/returned months past `dueDate()`.
  - `canSubmit()`'s reason shows on draft/returned months.
  - **Fill** (`fillMonth(int $monthlyReportId)`) calls `OpenMonthlyReport` and redirects. Upcoming months have no Fill (the action refuses future months).
- **To validate** is `MonthlyReport::query()->validatableBy($user)`. Its filters are `#[Url] city`, `project`, `month` (`Y-m`) and `status` (`submitted` is the default, then `validated` and `all`). They run in memory and use `x-ui.header-filter-select`.

**Show page** (`pages/monthly-reports/⚡show.blade.php`, plus `_show-header`, `_show-workflow`, `_show-modals`)
- Traits live in `app/Livewire/Concerns/MonthlyReports/`; the PHPStan host is `tests/PHPStan/MonthlyReportShowPageHost.php`.
  - `ReadsMonthlyReport`:
    - state: `#[Locked] int $monthlyReportId` and `#[Locked] string $renderedStatus` (sent as every action's `expectedStatus`);
    - computed: `report`, `periods`, `attribution`, `abilities`, `decidableRequest`, `submitBlocker`, `rows`, `incompleteLines`, `pendingMealLines`;
    - `forgetMonthlyReport()` unsets every computed and refreshes `renderedStatus`.
  - `EditsMonthlyReportLines`:
    - `public array $figures` is keyed by line id: `{value, numerator, denominator, not_measured, note, breakdowns.{male|female}.{field|disabled_field}, shares.{shareId}.{…}}`;
    - `updatedFigures()` sends that **whole line** to `SaveMonthlyReportLines`. The action recomputes from the input, so a partial line would blank fields;
    - `lines.0.*` errors are remapped to `figures.{lineId}.*`, with share and gender indexes turned back into ids;
    - any other error (stale) shows a toast and reloads;
    - a 403 shows a toast (`locked` / `not_allowed`) and reloads.
  - `RunsMonthlyReportWorkflow`:
    - modal booleans: `showSubmitModal`, `showValidateModal`, `showReturnModal`, `showReopenModal`, `showDecisionModal`, `showDeleteModal`;
    - methods: `openSubmitModal` / `submitReport`, `openValidateModal` / `validateReport`, `openReturnModal` / `returnReport` (`returnReason`), `openReopenModal` / `requestReopen` (`reopenReason`), `openDecisionModal(int)` / `decideReopen(bool)` (`decisionNote`, `#[Locked] decidingRequestId`; the request loads through `$report->reopenRequests()`), `markSeen`, `refreshLines` (toast `monthly_reports.lines_added`), `openDeleteModal` / `deleteReport` (redirects to the index).
- **Queries:** a fixed number of queries. The test asserts the same count for 5 and 40 split lines with breakdowns. Donor names come from `proposal.donor` (no pivot, so no money).
- **Components:**
  - `x-monthly-reports.lines-grid` (props `rows`, `figures`);
  - `x-monthly-reports.line-entry` (one line's or one share's inputs, by `MonthlyReportEntryKind`);
  - `x-monthly-reports.state-chip` (prop `state`, text + icon).
- **Enum-badge:** explicit arms for `MonthlyReportStatus` (validated good, submitted solid, draft outline) and `ActivityStatus` (completed/conducted good, started/ongoing solid, suspended accent, cancelled muted, not_started outline).
- **Lang:** `monthly_reports.*` (states, list, grid, workflow, modals, toasts) in en and ar, `titles.monthly_reports|monthly_report`, `navigation.monthly_reports`.

A refused row stays in the form.
- `ManagesMonthlyReportFiles`: `openFileModal(?lineId, ?entryId)` / `saveFile` (`newFileTypeId`, `newFile`) → `SaveMonthlyReportFile`; `confirmDeleteFile(id)` / `deleteFile` → `DeleteMonthlyReportFile`. Modal booleans `showFileModal`, `showDeleteFileModal`; ids `#[Locked]`. A file or line not in this report → 404 before any dialog.
- Activity rows: status select limited to `ActivityStatus::allowedFor(kind)`; reason for not started / suspended / cancelled; the date its status needs; note. Planned weeks `monthly_reports.planned_weeks` («الأسبوع 2 و3» / "Weeks 2 and 3"), carry-over badge `continuing_from` / `late_from` (late = text + warning icon). Evidence on an activity needs a saved entry first.
- Grid: 5th column "Evidence" (files, download links, missing required types `data-missing-evidence`, Attach).

**Generic Reports pages**
- A mirror shows the "Monthly report" chip (`reports.monthly_report_chip`, `data-monthly-report-chip`) linking to `monthly-reports.show`, on the index rows and the show header; the show page hides the files section. Edit/delete/submit/approve/return were already hidden by `ReportPolicy` (T17A).
- `ManagesReportForm` refuses a mirror in `openEditModal`, `saveReport` and `confirmDeleteReport` with the toast `reports.mirror_read_only`.
- **Numerator/denominator:** for a percentage/average indicator whose library entry has `numerator_label`, the form shows two inputs (library labels; denominator falls back to `monthly_reports.denominator`) and a read-only result (`ratioPreview()`). The server computes `value` (×100 for percentage, rounded to 2), stores `numerator`/`denominator`, and ignores any posted `value`. Zero denominator → `monthly_reports.zero_denominator`; percentage numerator > denominator → `monthly_reports.numerator_above_denominator`. Other indicators keep the single `value` input; their numerator/denominator are stored NULL.

## Patterns for T18
- **Grid:** rows are prebuilt in PHP (no view queries). Inputs carry `data-nav`. The keyboard handler sits on the grid root: arrows move (left/right flip in RTL), Enter moves down, Escape blurs. Codes use `<bdi dir="ltr">` and numbers use `tabular-nums`.
- **Filters:** `#[Url]` strings filtered in memory over one loaded set; `:value` is bound to the resolved value.
- **Status markers:** `x-monthly-reports.state-chip` for derived month states.

## UAT path (T28)
Roles as in the tests:
- owner: `Public Relations`, whose employee owns the project;
- officer: `MEAL`, the governorate officer through `meal_coverages`;
- decider: `mealManager()`, the slot holder.

Steps:
1. Activation generates the months.
2. The owner fills a month: **My reports → Fill**, then blur saves.
3. Submit, after the last working day.
4. The officer opens it from **To validate** and either validates it or returns it with a reason.
5. The owner requests a reopen on a validated month, and the MEAL Manager grants it, which puts the report back in draft.
