## Delivered contracts (exactly as on the branch)

### Slice 1: evidence types and the narrative question bank (§12.4, D-42, D-43)

**Schema**
- `evidence_types`: `id`, `name_ar` varchar(255), `name_en` varchar(255) null, `is_active` bool default true, `sort_order` unsigned int default 0, timestamps. Index `evidence_types_active_order_index` (`is_active`, `sort_order`).
- `narrative_questions`: `id`, `text_ar` varchar(1000), `text_en` varchar(1000) null, `frequency` varchar(20), `is_active` bool default true, `sort_order` unsigned int default 0, timestamps. Index `narrative_questions_active_order_index` (`is_active`, `frequency`, `sort_order`). `sort_order` is numbered 1…n **within each frequency**.

**Enum**: `App\Enums\NarrativeQuestionFrequency`: `Monthly = 'monthly'`, `QuarterEnd = 'quarter_end'`. It uses `HasTranslatedLabel`, with labels at `enums.narrative_question_frequency.*`. Slice 2 casts `report_template_questions.frequency` to the same enum.

**Models**
- `App\Models\EvidenceType`: `#[Fillable(['name_ar', 'name_en'])]`; `#[Scope] active()`, `#[Scope] ordered()` (`sort_order`, `id`); `localizedName(): string`; `isInUse(): bool`.
- `App\Models\NarrativeQuestion`: `#[Fillable(['text_ar', 'text_en', 'frequency'])]`; `#[Scope] active()`, `#[Scope] ordered()` (frequency, `sort_order`, `id`); `localizedText(): string`; `isInUse(): bool`.
- Neither model records activity: §15 has no keys for them, the same as `Sector` in T34.
- Both `isInUse()` return `false` for now (see "For downstream tasks").

**Policies**
- `EvidenceTypePolicy`: `viewAny` / `view` / `create` / `update` / `delete` → `evidence-types.manage`.
- `NarrativeQuestionPolicy`: the same abilities → `narrative-questions.manage`.
- In both, `restore` and `forceDelete` return false.

**Actions**: all `final`. Each calls `Gate::authorize` and runs in a `DB::transaction` with `lockForUpdate`.
```php
App\Actions\EvidenceTypes\SaveEvidenceType::handle(?int $evidenceTypeId, array $input): EvidenceType       // name_ar required ≤255, name_en ≤255; new = active, last
App\Actions\EvidenceTypes\DeactivateEvidenceType::handle(int $evidenceTypeId): EvidenceType                // already inactive → evidence_types.stale
App\Actions\EvidenceTypes\ReactivateEvidenceType::handle(int $evidenceTypeId): EvidenceType                // already active → evidence_types.stale
App\Actions\EvidenceTypes\DeleteEvidenceType::handle(int $evidenceTypeId): void                            // isInUse() or FK 1451 → evidence_types.in_use
App\Actions\EvidenceTypes\MoveEvidenceType::handle(int $evidenceTypeId, bool $towardsStart): int           // locks all rows by id, renumbers 1…n

App\Actions\NarrativeQuestions\SaveNarrativeQuestion::handle(?int $questionId, array $input): NarrativeQuestion  // text_ar required ≤1000, text_en ≤1000, frequency required (enum); new/changed frequency → last of its group
App\Actions\NarrativeQuestions\DeactivateNarrativeQuestion::handle(int $questionId): NarrativeQuestion
App\Actions\NarrativeQuestions\ReactivateNarrativeQuestion::handle(int $questionId): NarrativeQuestion
App\Actions\NarrativeQuestions\DeleteNarrativeQuestion::handle(int $questionId): void                         // isInUse() → narrative_questions.in_use
App\Actions\NarrativeQuestions\MoveNarrativeQuestion::handle(int $questionId, bool $towardsStart): int        // within its frequency; stale if the frequency changed meanwhile
```

**Pages and routes**: both pages are manage-only, because §8 has no `.view` permission.
- `GET /admin/evidence-types` → `pages::admin.evidence-types`, `->can('evidence-types.manage')`, name `admin.evidence-types.index`.
- `GET /admin/narrative-questions` → `pages::admin.narrative-questions`, `->can('narrative-questions.manage')`, name `admin.narrative-questions.index`. It has a `#[Url] frequency` filter (`x-ui.header-filter-select`).
- Sidebar: both entries sit in the Administration group, after Sectors, each behind its permission. Both permissions were also added to the group's `canAny`.
- Tour anchors: `data-tour="evidence-types-page"`, `"evidence-types-create"`, `"narrative-questions-page"`, `"narrative-questions-create"`.
- Lang groups: `evidence_types`, `narrative_questions`, plus `navigation.*` / `titles.*` (`evidence_types`, `narrative_questions`).
