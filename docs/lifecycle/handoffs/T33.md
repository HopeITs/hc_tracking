### Slice 2: template schema, due rule, pre-fill, confirm → activation (§12.4, D-04b, D-38, D-39, D-41, D-44) · **frozen at CP3**

**Schema** (migrations `2026_10_16_130736…130744`, `hasTable` pre-checks, `dropIfExists` down)
- `report_templates`: `project_id` FK unique cascade, `status` varchar(20) default `pending` (index), `confirmed_at`, `confirmed_by` FK users nullOnDelete, timestamps.
- `report_template_lines`: `report_template_id` FK cascade, `plan_indicator_id` FK restrict, `status` default `pending` (index `rt_lines_status_index`), `schedule` default `library_default`, `schedule_months` json null, `once_after_months` smallint null, `entered_by`, `fixed_denominator` uint null, `effective_from` date, `effective_to` date null, `confirmed_at`, `confirmed_by`, timestamps. - `report_template_questions`: template FK cascade, `narrative_question_id` null nullOnDelete, `text_ar`/`text_en` varchar(1000), `frequency` (`NarrativeQuestionFrequency`), `sort_order`, `is_active`, timestamps.

**Enums**: `ReportTemplateStatus` (`pending`, `confirmed`), `ReportTemplateLineStatus` (`pending`, `confirmed`, `retired`), `LineSchedule` (`library_default`, `monthly`, `selected_months`, `once_after_months`). Labels `enums.report_template_status|report_template_line_status|line_schedule`.

**Models**: `ReportTemplate` (morph key `report_template`, module `report-templates`, `project()`, `lines()`, `questions()`, `confirmedBy()`, `isConfirmed()`; no `#[Fillable]`), `ReportTemplateLine` (`template()`, `planIndicator()`, `evidenceTypes()`, `isDueIn()`; `status`/`confirmed_*` not fillable), `ReportTemplateQuestion` (`active()`, `ordered()`, `localizedText()`). `Project::reportTemplate(): HasOne`, `PlanIndicator::reportTemplateLines(): HasMany`. `EvidenceType::isInUse()` / `NarrativeQuestion::isInUse()` now read the new tables.

**`ReportTemplateLine::isDueIn(CarbonImmutable $month): bool`** — pure; reads `planIndicator.indicator.libraryIndicator` (eager-load it: zero queries when loaded).
- False unless `status = confirmed` and `effective_from ≤ M ≤ effective_to` (by month; null `effective_to` = open).
- `i` = whole months from `effective_from` (0-based, so `effective_from` is month 1).
- `library_default`: monthly/per-event → always; quarterly/semi-annual/annual → `(i+1)` multiple of 3/6/12; follow-up → `i == follow_up_months` (12 → month 13); per-season/baseline-endline/one-time → never; target without library link → never.
- `monthly` → always; `selected_months` → M's calendar month ∈ `schedule_months` (null → never); `once_after_months` → `i == N`.

**Pre-fill** (system writer, no Gate)
```php
App\Support\ReportTemplatePrefiller::prefillForProposal(Proposal $proposal): PrefillResult   // listener; donor-approved proposals only
App\Support\ReportTemplatePrefiller::prefillProject(Project $project): PrefillResult         // slice 4 backfill: all donor-approved proposals + HC.* annual-plan targets
App\Support\PrefillResult (readonly): list<int> $createdTemplateIds, $createdLineIds, $unlinkedPlanIndicatorIds, $missingFixedDenominatorLineIds; merge(), createdAnything()
App\Listeners\PrefillReportTemplates  // queued (auto-discovered) on ProposalStatusChanged(to = approved); tries 3, backoff [10,60,300]; inline-safe
```
- Skips `closed`/`archived` projects. One transaction per project; lock order **template first** (project never locked here).
- Line defaults: `library_default`; `entered_by` = library `collected_by`; `fixed_denominator` = `project_proposal.target_beneficiaries` when basis `fixed`; no evidence; window = months of the proposal's actual dates (planned if actual missing).
- HC.* (D-44): the project's `annual_plan` targets whose library code is `HC.%`; window = plan year ∩ project months.
- Questions copied only when the template is created. A confirmed template stays confirmed; new lines arrive `pending` (D-41).
- `report_template.pending` → responsible officer + MEAL Manager slot, after commit, only when lines were created.

**Actions** (`app/Actions/ReportTemplates`, `Gate::authorize('manage', …)` = `ReportTemplatePolicy::manage`)
```php
ConfirmReportTemplate::handle(ReportTemplate $template, array $lineIds): ReportTemplate   // @param list<int>
SaveReportTemplateLine::handle(ReportTemplate $template, int $lineId, array $input): ReportTemplateLine
    // @param array{schedule: string, schedule_months?: ?list<int>, once_after_months?: ?int, entered_by: string, evidence_type_ids?: list<int>, fixed_denominator?: ?int, expected_updated_at?: string} $input
RetireReportTemplateLine::handle(ReportTemplate $template, int $lineId): ReportTemplateLine  // confirmed only; effective_to = current month; never deletes
```
- Confirm: locks template → project; foreign/missing id → `ModelNotFoundException` (whole batch); non-pending line → `report_templates.stale`; unlinked → `link_library_first`; `library_default` on per-season/baseline-endline/one-time → `choose_measurement_months`; nothing confirmed overall → `confirm_at_least_one`. Approved project → `ActivateProject(…, 'template_confirmation')` in the same transaction (`ProjectActivated` once, after commit). Active project → activity `report_template.lines_added` (`proposal_ids`, `proposals`, `from_month`, `to_month`), no activation.
- `ReportTemplatePolicy`: `view` = `report-templates.manage` or project in `ownedProjectIds()`; `manage` = `report-templates.manage` AND employee = `MealCoverage::responsibleFor($project)` or `Slots::holderOf('meal_manager')`.
- Notifications: module `report-templates` in `config/notifications.php` (`ReportTemplateRecipients` = project owner direct; view permission `projects.view`).

**For T17A — lines of month M**: `$project->reportTemplate->lines()->where('status', 'confirmed')->with('planIndicator.indicator.libraryIndicator', 'evidenceTypes')->get()->filter->isDueIn($m)`, then keep lines whose target's proposal window covers M, grouped by `library_indicator_id` (§13.1 item 1).
