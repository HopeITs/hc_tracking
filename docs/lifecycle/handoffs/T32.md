### Actions (`app/Actions/Strategies`, each `Gate::authorize`s)
```php
final class SaveStrategicPillar  { public function handle(int $strategyId, ?int $pillarId, array $input): StrategicPillar }
    // @param array{code?: ?string, name_ar?: ?string, name_en?: ?string, goal_ar?: ?string, goal_en?: ?string, sort_order?: int|string|null} $input
final class DeleteStrategicPillar { public function handle(int $pillarId): void }
final class AssignProgramToPillar { public function handle(int $programId, ?int $pillarId): Program }   // null = "No pillar"
```
- **Save:**
  - An existing pillar loads through `$strategy->pillars()`, so another strategy's pillar is a `ModelNotFoundException` (BOLA).
  - Validation keys: `code` (required, max:20, unique per strategy), `name_ar` (required, max:255), `name_en` (max:255), `goal_ar`/`goal_en` (max:2000), `sort_order` (0–65535).
  - Messages are `strategies.pillar_*`.
- **Delete:** locks the row. Programs assigned → `pillar`: `strategies.pillar_has_programs`. A pillar already gone returns quietly.
- **Assign:**
  - Locks the pillar, then the program.
  - A pillar from another strategy → `pillar_id`: `strategies.pillar_other_strategy` («المحور من استراتيجية أخرى»).
  - A program without a strategy takes the pillar's strategy.
  - An unchanged pillar writes nothing.

```php
// app/Actions/Results
final class CopyResultTree { public function handle(Result $sourceRoot, Proposal $proposal): Result }
```
- **Authorization:** `Gate::authorize('results.create')` + `Gate::authorize('view', $proposal)`.
- **One transaction:**
  1. Lock the proposal row.
  2. `ProposalFramework::isStructureLocked()` without `results.update` → `structure`: `results_framework.structural_lock`.
  3. Reload the source as a `programFramework()` root (`parent_id` NULL, not an activity) whose `program_id` is in `ProposalFramework::programIds()`. Anything else → `source`: `results_framework.choose_a_framework_of_this_proposal` (BOLA).
  4. Already copied into this proposal (`copied_from_id` = the source root, checked under the lock) → `source`: `results_framework.framework_already_imported`.
- **Copy:**
  - Batched inserts, one level at a time (parents before children, old→new id map read back by `copied_from_id`), then all indicators in one insert (chunks of 500).
  - Query count follows tree depth, not size (tested: 1 vs 28 outputs).
- **Results:**
  - Copied: `statement`, `type`, `activity_kind`, `checkout_period`.
  - `program_id` = `ProposalFramework::sharedProgramId()` on every node (NULL for a multi-program proposal).
  - `copied_from_id` on every row; `contributes_to_result_id` = the source root on the new root, except a cross-cutting root.
- **Indicators:**
  - Copied: `name`, `library_indicator_id`, `code`, `measure`, `unit`, `baseline`, `frequency`, `copied_from_id`.
  - **`target` NULL**, `project_id` NULL.
- **Never copied:** `plan_indicators`, reports, `activity_schedules`, milestone links.
- **Activity log:** model events are skipped (query builder); after commit, one `result.created` is recorded on the new root (plan Q2).
