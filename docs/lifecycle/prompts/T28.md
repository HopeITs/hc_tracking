## UAT scenarios (each: preconditions, steps + expected, negatives, money check, Arabic check, evidence, Pass/Fail, defect id)
1. **Projects & Fundraising** (PR Manager; Financial for budget/agreement): create a project by HR center (city derived, no dates, ≥ 1 sector); **Similar Projects**; renewal = new proposal on the same project. Concept note with donor + project; skip with reason; **Plan** tab from the concept note. CN review with default reviewers + meeting time; submit with the unseen-reviewers warning (D-15). Proposal draft → Finance sets `requested_budget`; beneficiaries per center → review → submitted ("Awaiting funding"). `on hold` with a future reminder; reject (reason ≥ 10). **Approve Proposal** (actual dates, decision date, file or note): acknowledged owner → project `approved`, dated, "Awaiting MEAL template", **not active, no months yet**; unacknowledged → dated draft "Awaiting owner acknowledgement"; milestones/tasks shift; "No agreement recorded yet". **Change Status** shows only §2 targets, never `approved`.
2. **MEAL** (MEAL Manager slot): **Indicator Library** (server code, measure lock, deactivate); **Logical Framework** (impact → outcome → output → activity, cross-cutting root, contributes to a program result; **Start from Program Framework** with Micro urban and suggested targets); **Indicators & Targets** (empty vs 0, ≤ 100 %, a bad cell refuses the batch, columns = HR center + city); **Templates to confirm** (a per-season line needs months; confirming ≥ 1 line → project **`active`**, every month generated, one grouped `monthly_reports.generated`); validate / return (≥ 10) as the responsible officer, never their own; reopen decision; **Monthly Matrix** (filters, CSV); chain view (T16).
3. **Finance:** **Record Agreement** only on a donor-approved proposal; donor read-only; a second refused; one expected transfer per installment (`source = auto`); Finance fills transfer ≤ arrival ≤ receive dates, received amount, `fees`, exchange rate; re-recording creates nothing; the donor-report finance section is Finance-only.
4. **Center manager** (owner, Managers): acknowledge the assignment → `approved` (activation waits for MEAL); after confirmation every month exists, unstarted = "upcoming", never overdue; counts (0 allowed), notes, typed evidence; MEAL lines read-only; submit refused before the last working day and while M-1 is unsubmitted; locked after submit; **Request Reopen**; **My Reporting Duties**; **My Team** unless cut.
5. **Media and Finance departments:** a department task reaches **Department Tasks**; reminder settings; deliver file/link/text; accept or return with a reason; finance tasks hidden from other departments; the proposal shows name and description only.
6. **Aggregated donor report** (`reports.aggregate`): multi-center proposal, quarterly then semi-annual; only validated months; completeness section; percentages pooled, never summed/averaged; **Save as Donor Report** freezes; **Mark as Submitted** needs the final file; a no-money responsible sees it in **My Reporting Duties** without amounts.
7. **Oversight:** every movement of 1–6 reaches MEAL and General Management (immediate or digest per **Event Notifications**); one notification for a direct + oversight recipient; never the actor.
8. **Project = center:** a second open project for the same center **and program** refused, naming the existing one; another program accepted; a new proposal on a closed project returns it to a dateless draft; closed/archived don't block; an inactive center can't be picked.
9. **No-money user** (PR Manager, MEAL, Managers, Media Team): no amount in pages, modals, timeline, notifications, digest emails, CSV, **My Reporting Duties**, **Department Tasks**, **Donor Report Builder**, **Similar Projects**, logframe; links only with view permission.
10. **Disaggregation + activities** (seeded, D-54): male/female + PwD, an `entered` ratio, Ongoing and Conducted; totals match a prepared calculation; Ongoing reappears next month.
11. **Closing (D-02c):** `active → completed` refused until the final-report milestone, the file and the recorded acceptance; succeeds without the email.
12. **Fixed denominator (D-25):** 36 with 180 beneficiaries → 20 % in report and matrix; donor report pools Σ counts ÷ Σ beneficiaries over two centers.
13. **Reopen (D-09a):** MEAL Manager slot empty → PR Manager decides; a MEAL officer → 403; never the preparer.
14. **Coverage (D-12a):** an Aleppo officer assigned to an Idlib project validates it; the Idlib officer doesn't see it.
15. **Codes (D-10a):** a new Micro indicator gets the next code (e.g. `002.OP1.2.4`); the picker lists only the proposal's programs + institutional entries.
