## Goal
The center manager fills and sends a month in one screen; MEAL validates or returns it from the same page without any figure input.
- **Monthly Reports** (`/monthly-reports`): "My reports" (every generated month of the user's projects) and "To validate" (MEAL's queue).
- **Monthly Report** (`/monthly-reports/{monthlyReport}`): one keyboard-friendly grid of lines with shares, breakdowns and computed values, plus the workflow actions.
- **Slice 1 (days 9–10):** routes, Sidebar, `SubjectLinks`, list page, show page with the lines grid and every workflow action.
- **Slice 2 (day 11):** activities this month, answers, typed evidence upload/download, the generic Reports page guards, and numerator/denominator in `ManagesReportForm`.

## Rules
- **Routes:** `Route::livewire('monthly-reports', 'pages::monthly-reports.index')->can('reports.view')->name('monthly-reports.index')`; `monthly-reports/{monthlyReport}` → `pages::monthly-reports.show`, `monthly-reports.show` (slug binding, policy `view` in `mount()`); `monthly-reports/{monthlyReport}/files/{monthlyReportFile}/download` → a rate-limited controller shaped like `ReportFileDownloadController`, loading the file through `$monthlyReport->files()` (`contracts.md §13.1` item 4). `#[Title('titles.monthly_reports')]` / `titles.monthly_report`.
- **List, My reports:** projects from `ownedProjectIds()` (plus supervisees when T23 is merged); every generated month with its state: upcoming, draft, submitted, validated, returned, reopen pending; due date and an overdue marker, never on upcoming months. **Fill** opens the existing report (no "Open" state: months are generated, D-29). Show `canSubmit()`'s reason when Submit is blocked. Empty states explain why (project not active yet; nothing to validate).
- **List, To validate:** T17A's validate-queue scope (the responsible officer's projects, all for the MEAL Manager, and projects with no responsible officer for any MEAL user). Filters city, project, month, status via `x-ui.header-filter-select`.
- **Header:** `x-ui.detail-header` with project, month (`translatedFormat`), status badge (text + icon), preparer, submitted/validated meta, seen flag, return reason, and the owner–center warning when `ownerCenterMismatch()` (never blocks).
- **Grid** (`resources/views/components/monthly-reports/lines-grid.blade.php`, reusing T13's keyboard pattern):
  - fixed columns: code (LTR-isolated), name in the user's language with the other as a secondary line and `frequency_note` under it, target (value + period), input(s), note, files;
  - counts: one input; `fixed` percentages: the count only (labelled `numerator_label`), the denominator read-only «من أصل :count مستفيدًا في المقترح» / "out of :count beneficiaries in the proposal", the computed % read-only; `entered` ratios/averages: numerator + denominator, a read-only computed value, and a **Not measured this month** toggle;
  - `split`: one sub-row per donor share (donor, proposal, target) and an automatic total; `shared`: one row;
  - disaggregated: male / female, each with "of whom persons with disabilities";
  - `meal` lines are read-only for the manager with a "Filled by MEAL" badge; the validator gets their inputs while `submitted`;
  - `role="grid"` or a labelled table; `aria-label` = indicator + column; arrows move, Enter moves down, Escape leaves; arrows flip in RTL (`rtl:-scale-x-100`).
- **Autosave in draft:** `wire:model.blur` on figures, notes and answers; each blur calls `SaveMonthlyReportLines` for that line only and shows its error inline. Submit waits for pending saves (`wire:loading` on the save targets).
- **Inputs exist only** for the preparer side in draft (and the validator on `meal` lines while submitted). Submitted and validated reports render read-only. MEAL never sees manager inputs.
- **Actions** by ability, each calling T17A's action with `expectedStatus`: Submit (confirm modal listing incomplete lines; zero is a value; disabled with the reason before the month's last working day or while the earlier month is unsubmitted); Validate (disabled with the reason while `meal` lines are pending); Return (reason ≥ 10); Request Reopen (validated, preparer side, none pending); Decide (grant / deny + note); **Mark as Seen** (any status; shows who/when); **Refresh Lines** (draft; reports how many were added; new lines appear sorted without moving focus); delete draft. Reopen request history is listed.
- **Modals:** Flux bound with `wire:model` booleans `showSubmitModal`, `showValidateModal`, `showReturnModal`, `showReopenModal`, `showDecisionModal`, `showDeleteModal`; never `:open`.
- **Activities (slice 2):** each activity with its status select (only `ActivityStatus::allowedFor()` its kind), the inputs its status requires (§13), the planned weeks («الأسبوع 2 و3» / "Weeks 2 and 3"), and the carry-over badge «مستمر من :month» / "Continuing from :month" or «متأخر من :month» / "Late from :month".
- **Answers (slice 2):** the template questions T17A returns for the month; quarter-end ones labelled.
- **Evidence (slice 2):** per line and per activity entry: evidence type select (active types), upload via `SaveMonthlyReportFile` (`SecureUpload`, 5 MB, `FileType`, the report detail page's messages), download via the new route, delete via `DeleteMonthlyReportFile`; required types not yet attached are listed.
- **Generic Reports pages (slice 2):** a mirror shows a "Monthly report" chip linking to its report and no edit, delete, submit, approve, return or file controls; `ManagesReportForm` refuses to open or save a mirror.
- **`ManagesReportForm` (slice 2):** for a percentage/average indicator whose library entry has `numerator_label`, two inputs (labels from `numerator_label`/`denominator_label`) and a read-only computed value; the server computes `value` (×100 for percentage) into `reports.value` and stores `reports.numerator`/`denominator`; never accept `value` from the request for these. Zero denominator → T17A's `zero_denominator` message. **Never cut** (README cut list).
- **Security:** hold only ids, `#[Locked]`; never trust status or preparer from state. Data helpers are `protected` or `#[Computed]` (`BrowserCallableMethodsTest`). The component checks the policy before opening a modal (UI only); the action authorizes. A lost permission → the action's 403 and a toast. Links to projects, proposals, donors render only with their view permission. No money.
- **Concurrency:** a locked or stale message on blur → toast, then one `forgetMonthlyReport()` helper unsets every computed (report, lines, shares, files, activities, answers, requests, abilities) and the page re-renders from the server. The same helper runs after every write.
- **Queries:** the show page loads in a fixed number of queries (report + project, lines with shares, breakdowns, plan indicator, indicator, library entry, files, activities, answers, requests), shaped in PHP. Achievement only from `achievedValue()`/`percentAchieved()`.
- **UI:** every string in `lang/en` and `lang/ar` (`monthly_reports.php`, `titles.php`, `navigation.php`), Arabic plurals with explicit ranges; logical classes; Graphite tokens in both themes; no `@php(...)`; enum-badge tones for `MonthlyReportStatus` and `ActivityStatus` with explicit arms; stable `data-<name>` tour hooks (see `config/tour.php`) on the list intro, grid, submit and validate.
- **Sidebar:** "Monthly Reports" in Monitoring & Evaluation under `reports.view`. `SubjectLinks`: `'monthly_report' => showRoute('monthly-reports.show', MonthlyReport::class, $id)`.
