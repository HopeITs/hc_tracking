# T26 · Arabic/RTL quality, guided tours and the user guide · B4 · days 6–12 (guide before CP6) · 4 slices

## Goal
Staff work Arabic-first on the corrected path (README "The story"), and T28 runs every scenario in Arabic. This task gives every UI task one **checklist** (below; also the reviewers' list), builds the automated guards behind it, adds the **guided tours**, and rewrites both user guides to the corrected story. ## UI checklist (copy into every UI task's PR description; reviewers tick it)
```
[ ] Strings: no literal UI text in Blade/PHP; every key in lang/en AND lang/ar (group file per module, enums.php, titles.php, navigation.php, notifications.php events.*); LocalizationTest green
[ ] Validation: every message of the task (validate() arrays, ValidationException::withMessages) resolves to a key in both languages; none falls back to Laravel's English sentence in the Arabic UI
[ ] Arabic reads naturally with the unified terms: المذكرة المفاهيمية، المقترح، الاتفاقية، الأثر (Impact)، النتيجة (Outcome)، المُخرَج (Output)، النشاط (Activity)، المستهدف، التحقق; doubtful terms flagged for MEAL/Finance
[ ] Plurals use explicit ranges {0}|{1}|{2}|[3,10]|[11,*]; every :placeholder of the English text survives
[ ] Direction: logical classes only (ms/me/ps/pe/start/end/text-start/text-end/rounded-s/e/border-s/e); directional icons get rtl:-scale-x-100; grids and arrow-key navigation follow the reading direction
[ ] LTR islands: codes (R8.A1.I1, 002.OP1.2.3), numbers, project numbers (x-ui.project-number), URLs in <bdi dir="ltr">; mixed AR/EN cells dir="auto"; dates via translatedFormat(__('formats.date'))
[ ] Enums: labels via $case->label() in both languages; stored values stay English; status never by colour alone
[ ] Long Arabic labels wrap or truncate with a title; never clipped meaning
[ ] No amount in any toast, notification, email, tour copy or empty state for users without the money permissions
[ ] Messages/emails/notifications of the task render in both locales (tested)
[ ] New page: Arabic render test (<html lang="ar" dir="rtl">, Arabic title, one Arabic enum label) + English twin; tour hooks listed in handoffs/TNN.md
[ ] Visual check en + ar, light + dark, desktop + 375 px (server-side preview per .ai/rules/pages.md, then delete public/__preview.html), or screenshots from the developer
```

## Rules
- **Scope boundary:** do not change a feature's behaviour, queries, validation logic, permissions or layout. A problem outside direction classes, text and hooks goes to the owning task as a follow-up (note it in your handoff). Do not translate stored values or rename enum values. Do not regenerate the `.docx` guides (follow-up).
- **Lang hygiene:** keys live in `lang/en/<module>.php` and `lang/ar/<module>.php` with identical key sets; `lang/ar.json` holds only vendor sentence keys; never name a group file `results`, `of`, `to`, `files` or `showing`. Parallel edits of the same lang file: keep both keys, rerun `LocalizationTest`. Shared words go in `common.php`.
- **Notification sentences:** every event key in T21's `EventCatalog` (immediate and digest) and the monthly digest email has an Arabic and an English sentence, checked in each sweep.
- **Indicator names** show in the user's language, the other language as a secondary line.
- **Tours:**
  - copy lives in `lang/{en,ar}/tour_pages.php` under `pages.<route_key>.<id>` (route name with `.` and `-` replaced by `_`); steps are declared in `config/tour.php` `pages`; the stale comment in `config/tour.php` that says `lang/*/tour.php` is corrected;
  - a step with no visible target is skipped, so tab steps appear only when that tab is open (the intro must read well without them) and cut features simply lose their step;
  - tours only target elements the page already renders for that user; never render a hidden money element so a step can reach it; hooks carry no record ids; copy explains what the user sees and does and never contains data or amounts;
  - existing hook style: `data-my-work`, `data-detail-header` (bare `data-<name>` attributes).
- **Required tours** (intro + steps, en + ar; verify route names in each handoff):

| Tour | Task | Page |
|---|---|---|
| Indicator Library | T11 | `indicator-library.index` |
| Reviewers panel | T07 | `proposals.show` |

  Every **other** new page route (evidence types, narrative questions, sectors, MEAL coverage, etc.) gets at least an `intro`. Supervision tab and the My Team card (T23) get steps only if their hooks shipped.
- **Guides:** write for staff, task-oriented and short; bold UI names exactly as rendered in each language (Arabic from `lang/ar`); keep each guide's tone, numbering and headings (`grep -c '^#'` equal in both files); no screenshots unless supplied; no amounts or real donor data in examples; money is described as role-limited ("Hide money, keep names").
