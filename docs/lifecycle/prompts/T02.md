Arabic labels reuse the existing Arabic UI terms.

**Out:** policies and actions that use these names (later tasks); new roles; sidebar links; running sync anywhere but the local DB (T29).

## Rules
- `reports.reopen` is held by MEAL + Public Relations Manager, but `MonthlyReportPolicy::decideReopen` (T17) narrows it to the MEAL Manager slot or the fallback. This task only grants.
- `reports.aggregate` doesn't end in `.view`, so it never falls into `$viewEverything`. Assert that.
- `permissions:sync` only adds. A permission an admin removed by hand stays removed; one added by hand stays.
- Deploy order (for T29): `optimize:clear` → `permissions:sync --dry-run` → `permissions:sync`.
