## Rules
- **Code:**
  - generated by `IndicatorCode::next()` inside the save transaction (lock the (`program_id`, `level_ref`) rows);
  - program code from HR (`HrProgram`); `HC` when institutional;
  - a duplicated HR program code → refused «رمز البرنامج مكرر في HR، اطلب تصحيحه من فريق HR» / "This program's code is duplicated in HR. Ask the HR team to fix it.";
  - changing program or `level_ref` is allowed only while unused, and regenerates the code; frozen after first use.
- **Names:** `name_ar` required, `name_en` optional; display in the user's locale, with the other language secondary (`dir="auto"`), code LTR-isolated.
- **Measure lock:** once any linked `indicators` row has `plan_indicators`. Re-check inside the transaction after `lockForUpdate()`, never from page state. When unlocked, a change propagates to every linked `indicators.measure` in the same transaction.
- **Percentage targets are 0–100**, never 0–1. `average` has no 100 cap. `follow_up_months` is required when the frequency is `follow-up`. `denominator_basis` applies to percentage only, defaulted from `collected_by`; MEAL can override.
- **Unique people (D-25):** no flag. MEAL writes "new individuals this month" in `definition` and the field label.
- **Delete** is refused while any `indicators` row references the entry (the FK `restrictOnDelete` is the backstop; catch it → the "in use" message). **Deactivate/Reactivate** instead: a deactivated entry stays on existing uses and isn't offered for new selection.
- `is_cumulative` is stored and shown; achievement for cumulative indicators is applied by T17/T18 through the template, not here.
- **Authorization:** `indicator-library.view` (route `->can()` + `viewAny`); create/update(+deactivate/reactivate)/delete. `Gate::authorize` in every action; `#[Locked]` ids; reload by id. `#[Fillable]` excludes `code`, `serial`, `is_active`. No money.
- **Audit:** `TracksActivity` + `RecordsActivity`; events per §11.1. Register them in `App\Notifications\EventCatalog` (T21; digest importance; MEAL + GM oversight). If T21 isn't merged, add the keys and tell Dev 3.
- **Arabic search** in memory: normalise both sides (strip U+064B–U+065F, U+0670, tatweel U+0640; unify أ/إ/آ → ا); cap the term with `Like::term()`.
