## Scope
**In:**
- Header (`detail-header`): breadcrumbs (and the T38 back link if merged), title + `project-number`, status badge, `meta`: program · center · city · owner chip; `summary`: one line "start → end · schedule verdict" (`schedule-status`), or "No dates yet" for drafts, plus the funding badge. Remove the separate schedule block that repeats the dates.
- Tiles row: headline target · open milestones · open tasks · (money viewers only) funding envelope. **Start/end tiles and demographic total removed** (they live in the header line and the beneficiaries section).
- Disclosure sections, closed by default: **Description**, **Beneficiary breakdown** (with the demographic total as its header count). Open state per section remembered in `localStorage` key `project-show:<section>` (per viewer convenience only; render correctly without it; wrap in try/catch).
- **Funding sources** panel removed; its rows join the Proposals tab as a column/section (same money guard: query only for money viewers).
- Default tab stays `milestones`; tabs keep their names and `?tab=` deep links.
**Out:** the Risks tab (T51), new data, the project form (T58), adding indicators (T56), the proposals page, any new query that reveals money to non-money roles.

## Rules
- "Hide money, keep names": the funding envelope tile and the funding rows in the Proposals tab render only for holders of the money permissions; the query is skipped server-side for everyone else (existing `FundraisingPagesMoneyTest` pattern; extend it for the moved rows).
- Each fact once. The duplication map is the review checklist.
- Disclosures use the Flux component available in the installed version; if none, a minimal Alpine `x-data="{ open: false }"` with `aria-expanded`, `aria-controls`, keyboard-operable button; no `@php(...)`.
- Keep every existing `data-` tour hook; where a hooked element moves, move the hook with it and list it in the handoff.
- Logical classes; works at 375 px (header line wraps, tiles 2 × 2).
