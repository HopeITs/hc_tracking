## Deviations from contracts.md / the prompt
- **Template lines extended (Q1, approved with the plan).** `ExtendProposal` moves `report_template_lines.effective_to` from the old end month to the new end month for the proposal's non-retired lines (§12.4). Without it the new months would be generated with no lines. No `report_template.lines_added` notification is raised. Dev 1 to confirm.
- `DeadlineCatalog` read `planned_date_end`, not `actual_date_end` (Q2): switched for active proposals only.
- The generic `proposal.status_note_added` activity is skipped for `extension` notes too (as for `negotiation`), so the owners get one notification.
- The amendment link in the time vital is not possible (a vital is a caption); it sits in the funding-tab chronology cell and in the status timeline.

## Left on the original end (they never show an actual end date)
`calendar/⚡index` tone (`actual_date_end` only picks the colour), `ReadsProposalRegister` and `ReadsProjectFunding` (select the column but do not display it), `RebaseProposalPlan` (clips plan dates at approval), `SaveProposalMilestone` (column pairs), `ShiftActivitySchedulesOnApproval` (begin only).
