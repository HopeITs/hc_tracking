### Panel `todo`
- `Panels::definitions()`: `'todo' => ['icon' => 'check', 'size' => 'S', 'rows' => 4, 'register' => null, 'allows' => $everyone]`. It isn't in any `RoleLayouts`, `PageLayouts` or `ReadyLayouts` entry. `ReadyKinds['todo'] = 'work'`, so the Customize sheet lists it under the Work group in "Add".
- Component `resources/views/components/desk/panels/⚡todo.blade.php` (`IsDeskPanel`). Constants `MaxLength = 200`, `MaxItems = 100`.
- Public actions. Each one reads through `auth()->user()->todos()`, so another user's id gets a 404 and nothing changes:
  - `add(string $title): bool`: trimmed, `required|string|max:200`, and refused when the list already holds `MaxItems`. Goes last among the open lines.
  - `toggle(int $id): void`: done ↔ open. `done_at` is set or cleared. A reopened line goes last among the open ones.
  - `remove(int $id): void`
  - `reorder(array $ids): void`: puts the open lines in this order. Ids that are done, unknown or someone else's are ignored. Open lines left out keep their order after the listed ones.
  - `move(int $id, int $position): void`: the `wire:sort` drop handler. It works out the new order and calls `reorder()`.
  - `clearDone(): void`
- UI:
  - The header count is the number of open lines.
  - Enter in the input adds a line.
  - Each line is a `role="checkbox"` button with `aria-checked`, so Space ticks it. Delete removes the focused line and moves focus to the next one (`aria-keyshortcuts="Delete"`).
  - Drag uses the grip (`wire:sort:handle`) and works on open lines only.
  - Done lines sit below the open ones, under "N done · Clear done".
  - An empty list shows "Nothing on your list" and focuses the input with `preventScroll`.
  - Only `.dk-todo-scroll` scrolls, so the card keeps its S height. The row uses logical (start/end) direction, so in Arabic the checkbox sits on the right.
- Lang: `desk-cards.todo.*`, `desk-cards.tagline.todo` and `desk.panel.todo.{title,description,locked}`, in en and ar. The Arabic title is «قائمتي» and lines are «بند», so they aren't confused with the Tasks panel («المهام»).
- No activity log, no notifications, `desk_notes` untouched.

## Deviations from contracts.md / the prompt
- Branch `scenarios-workflow` instead of `wave2/W-27-todo-panel` (user's choice).
- `move(int $id, int $position)`: a sixth public method, needed because `wire:sort` sends `(item, position)`, not the full id list. It is exempted like the other five.
- `clearDone()` is also in the exemptions. The prompt only listed four methods, but this one writes too.
- `MaxItems = 100`: a cap per user that the prompt didn't ask for, so a single user can't fill the table without limit.
- Reordering is by drag only (user decision). There's no keyboard move.
