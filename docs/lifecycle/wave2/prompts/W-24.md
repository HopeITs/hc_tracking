## Rules
- Migration: `concept_note` text null after `notes`; `down()` drops it.
- `SaveProposal`: `conceptNote` nullable string, max 20 000 chars, trimmed, blank → null. The file goes through the existing `SaveProposalFile` path with the new collection (no new upload code).
- Form: section "Concept note": textarea (`dir="auto"`) **and** file field; at least one is not required (the transition keys do not change).
- Status tab, ideation phase only (`ProposalPhase` says which): a card "Concept note" with title, donor name, created date, the text (rendered as paragraphs, no HTML), and the file row with the protected download. Outside ideation the card collapses to one line "Concept note · view" that expands.
- Activity: `proposal.concept_note_updated` (names only; register in `EventCatalog` as digest). No notification.
- Lang: `proposals.concept_note.*` in both languages.
