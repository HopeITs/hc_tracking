# W-02 · "Add center" form and the inactive-center pause · Dev 2 · M (1–2 days) · 2 slices

ClickUp: https://app.clickup.com/t/123jdbarcyr

## Goal
The project form reads as **"Add center"**: city → program → physical center (optional, filtered by city) → host center (required when no physical center, W-01) → owner → sectors, with the name pre-filled as "Program — Center/City". Legacy projects stop showing "No center" in the proposal picker because the mapping command has run. When HR marks a center inactive, every row shows it (D-66) and the project's **non-report** work pauses: its tasks and scanner alerts stop firing, report tasks keep going, nothing is closed.
- **Slice 1:** form, naming, mapping command run, badge.
- **Slice 2:** pause rule and scanner exclusions.

## Slice 2 · pause rule (D-66)
- One definition: `Project::isPaused(): bool` = physical center exists and is inactive (a hosted project is never paused by its host). Add `Project::scopeNotPaused(Builder $q)` that filters in SQL through the remembered inactive-center id list (no `whereHas` across connections: pass the ids with `whereNotIn`/`whereNull`).
- Scanners: `DeadlineCatalog::items()` drops items of paused projects **except** `TaskKind::Report` tasks and donor-report items; `ProjectDatesScanner`, `StalledScanner`, `DataGapScanner`, `OffTrackIndicatorScanner` skip paused projects. Add the rule in one place each (a `->notPaused()` call), never by re-reading HR inside a loop.
- Tasks: a task of a paused project shows a "Paused: center inactive" chip in the Tasks panel, the department tasks page and the task page; its due date stays; no status change. The quick "Add task" on a paused project is allowed (nothing is blocked), only alerts pause.
- Reminders (`OnHoldReminderScanner`) and donor-report duties are untouched.
- Record the rule with Boost `record-rule` on `app/Notifications/Alerts/**`: "Items of paused projects (inactive center) are excluded in DeadlineCatalog/scanners except report tasks and donor reports (D-66)". Only after the developer confirms.

Messages (`lang/{en,ar}/projects.php`, `tasks.php`): "Center inactive" / «المركز متوقف»; "Paused: the project's center is inactive. Report tasks continue." / «متوقف مؤقتاً: مركز المشروع غير فعّال. مهام التقارير تستمر».
