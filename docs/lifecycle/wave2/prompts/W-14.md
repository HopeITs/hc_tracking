## Rules
- One definition: `EmployeeProfile::isDepartmentManager(): bool` = the employee's current contract's position has a job level whose name matches a config value `config('access-control.department_manager_job_level')` (default "Department Manager – Grade 5"; match on a normalised string, since HR may store the dash differently). Read through the remembered HR lookups; no `whereHas` across connections.
- `User::canSeeDepartmentTasks()` delegates to it; the `department` option and the page are hidden (not disabled) otherwise, and the server refuses the scope value with a 403-equivalent (reset to `mine`, as `updatedScope` does today).
- Super Admin keeps everything through the administrator-roles rule; `Managers`/GM roles get the scope **only** if their HR job level matches (D-65 is explicit).
- `TeamScope` (`team`) unchanged.
- Record the rule with Boost `record-rule` on `app/Support/EmployeeProfile.php` after the developer confirms.
