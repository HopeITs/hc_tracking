# W-01 · Host center on projects · Dev 1 · M (1–2 days) · 1 slice

ClickUp: https://app.clickup.com/t/123jdbarcyq

## Goal
A project in a city with no HR center (Idleb today) can exist as a draft **hosted by** another HR center (D-55): the project keeps `city_id`, has `center_id = NULL`, and names the HR center that follows it up in a new `projects.host_center_id`. The responsible person stays the existing project owner (`projects.user_id`). Everything that keys on the center (the one-open-project rule, the proposal project picker, `MealCoverage`) keeps working for hosted projects, and every row that shows a hosted project says so.

## [contract] · authorised by D-55
Append to `contracts.md §7` under **T30**:
> **W-01:** `projects.host_center_id` unsigned big int null, indexed `projects_host_center_id_index`, **no FK** (HR connection). Rule: a project has a physical center (`center_id`) **or** a host center (`host_center_id`), never both and never neither once W-02 ships; `city_id` is always set. The open-project rule keys on `(center_id ?? city_id, program_id)`: `Project::openProjectFor(?int $centerId, int $cityId, int $programId, ?int $exceptId = null): ?Project` — when `$centerId` is null it matches projects with `center_id IS NULL` in that city and program.

Replace the `openProjectFor` signature in `§3` with the one above.

## Rules
- Migration: add the column after `center_id`; pre-check that it does not exist; `down()` drops it. No backfill.
- `SaveProject`: accepts `hostCenterId` (nullable int, must be an **active** `HrCenter` id, must differ from `centerId`); when `centerId` is null, `cityId` is required and comes from the input (today it is derived from the center, lines 85–86); when `centerId` is set, `city_id` keeps being the center's city and `host_center_id` is forced to null. Legacy rows with neither value stay saveable until W-02 (do not refuse an edit that does not touch center fields).
- `Project::openProjectFor()` as in the contract; `SaveProject`, `RestoreProject`, `ReopenProjectAsDraft`, `LinkProposalProject` keep calling it (search for every caller, none may be left on the old signature).
- `Project::hostCenter()` is a `RemembersHrLookup`-style accessor on `HrCenter::remembered()`, never a cross-connection relation. Add `Project::locationLabel(): string` = center name, else "{city} · hosted by {host center}" (translated), used by every list and card below.
- Badge **"Hosted by {center}"** / «يتابعه مركز {center}»: project index rows, project story header, the proposal project picker rows, the desk Projects panel card (`components/desk/panels/⚡projects.blade.php`, dates lens untouched). Text + icon, never colour alone.
- `MealCoverage::responsibleFor()`: unchanged for physical centers; for a hosted project it resolves by **city** (confirm with the existing city-level assignment; if the class has no city path, stop and ask).
- Form (W-02 owns the redesign): in this task only add the host-center select to `_index-project-modal.blade.php` under the center select, shown when no center is chosen, so the rule is reachable. Lang keys in `lang/{en,ar}/projects.php`.
- Activity: the host center change is recorded like the center change (names only).

Messages: "Choose a physical center or a host center." / «اختر مركزاً فعلياً أو مركزاً مضيفاً»; "A project cannot be hosted by its own center." / «لا يمكن أن يستضيف المركز مشروعه».
