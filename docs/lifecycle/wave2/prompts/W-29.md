## Rules
- Tokens: `--radius-panel: 0.75rem` and `--color-panel-border` (alias of the existing line token, Graphite-safe) in `tokens.css`; `x-ui.panel` and `.dk-panel` read them; no raw hex, no new colours.
- `x-ui.section` (`components/ui/section.blade.php`): props `title`, `description`, `actions` slot, `padded` (default true); renders a heading (`h2`/`h3` via a `level` prop, default 2), uppercase tracking heading in the muted ink token, a divider, then the slot; no border, no shadow. `data-section` attribute from a `key` prop for tests.
- Replace each inventoried div with `x-ui.panel` (when it had a border and a filled background) or `x-ui.section` (when it only grouped content). Keep markup inside untouched; keep every `wire:key`, `data-test`, `data-tour`, `id` and `aria-*` on the new root.
- Light mode stays pixel-identical except the border colour/radius unification; dark mode uses Graphite tokens only (`DesignTokensTest`).
- One PR per slice; each PR includes before/after screenshots of two pages (both themes, both directions, 375 px and desktop) in the description.
