ClickUp: https://app.clickup.com/t/123jdbarcyz

## Goal
From the proposal form, Public Relations can add a donor that does not exist yet. The donor is a **pending request** until the General Manager approves it on the Donors page (D-57: Freddy = CEO = `General Manager` role). While the chosen donor is pending, the proposal form shows "Donor request pending" and **refuses to save**. Existing donors are approved by migration.

## Rules
- Migration: columns + backfill `approval_status = 'approved'` for every existing row (default covers it; write the pre-check anyway); `down()` drops the four columns.
- `SaveDonor`: when the actor lacks `donors.approve`, a **new** donor is created `pending` with `requested_by`; when the actor holds it, `approved`. Editing never changes the status.
- New `ApproveDonor::handle(Donor $donor, User $actor): Donor` and `DeclineDonor::handle(Donor $donor, string $reason, User $actor): void` (decline deletes the pending row only when it is referenced by no proposal; otherwise it stays pending with the reason stored in `notes` and the requester is told). `Gate::authorize('approve', $donor)`; lock; `expected` status guard (`pending`); activity + notification after commit.
- Proposal form: "Add donor" opens the existing donor modal in a nested flow (reuse `ManagesDonorForm`; do not copy it); after save the new donor is selected and a banner "Donor request pending — the General Manager must approve it before this proposal can be saved" shows; `SaveProposal` adds the rule `donor must be approved` with the translated message (server-side, also for edits that change the donor). An existing proposal whose donor is pending (only possible through the admin path) cannot be transitioned either: add the check to the `donor` requirement key meaning in `ProposalTransitions` **without** changing the key table (the key already exists on the first move).
- Donors page: a "Pending requests" section at the top for `donors.approve` holders (requester, date, Approve / Decline with reason modal); pending donors are badged "Pending" everywhere they appear (register, donor page, proposal vitals) and excluded from the donor pickers of other users until approved (the requester sees it, badged).
- No money. Activity records names only.

Messages (`lang/{en,ar}/donors.php`, `proposals.php`): "Donor request pending. The General Manager must approve it first." / «طلب المانح قيد الموافقة. يجب أن يوافق المدير العام أولاً»; "Donor approved." / «تمت الموافقة على المانح»; decline reason required (min 10).
