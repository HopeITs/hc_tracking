## Rules
- Table `user_todos` (`id`, `user_id` FK users cascadeOnDelete, `title` varchar(200), `is_done` bool default 0, `done_at` datetime null, `sort_order`, timestamps; index `(user_id, is_done, sort_order)`). Model `UserTodo` with `UserTodoPolicy` (owner only, every ability); factory.
- Panel `todo`: registered in `Panels::definitions()` (icon `check`, size `S`, rows 4, `allows` everyone, `register` null), **not** in any role's starting layout (people add it). Lives in `components/desk/panels/⚡todo.blade.php` with `IsDeskPanel`.
- Actions on the component (owner-scoped: load through `auth()->user()->todos()->whereKey($id)`): `add(string $title)`, `toggle(int $id)`, `remove(int $id)`, `reorder(array $ids)`; validation 1–200 chars; done items sink to the bottom and are cleared by "Clear done". Add the four methods to `authorizationCoverageExemptions()` with the reason "Saves only the signed-in user's own to-dos".
- Panel body: input + list with checkboxes (`aria-checked`), keyboard: Enter adds, Space toggles, Delete removes focused item; empty state "Nothing on your list" with the input focused; count in the panel header.
- Lang `desk-cards.todo.*` in both languages. No activity, no notifications.
