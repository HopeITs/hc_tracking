# M-06 · monthly-reports · handoff

ClickUp: https://app.clickup.com/t/123jdbau1qp · Branch: `meeting/M-06-monthly-reports` (from `main` @ e17ee8cc) · Not committed.

## Scenario
- **Preparer (My reports):** "Which month do I fill now, and is any late?" Job: Fill in the next month, 1 click from the top row.
- **MEAL (To validate):** "Which submitted report has waited longest?" Job: "Validate the oldest", 1 click.

## What changed
| Area | Change |
|---|---|
| Filters (both tabs) | Visible: search + **Proposal**. Behind **More filters**: City, Program, Center, From, To, Status (To validate only). The block opens by itself while one of those is set or From / To is refused. Clear stays in the bar. |
| My reports | One table (`mineRows()`): Place (+ proposals) · Month · Status · Due · actions (view, matrix, Fill in). Order: overdue → can fill → draft/returned → submitted → reopen pending → upcoming → validated, then month, place, id. Removed: the "Needs you" list, the month strip, the validated fold, per-place headings. Search now works on this tab too (place or proposal). 25 rows, then "Show more". The count badge shows the row count. |
| Empty states | One button each: **Clear filters** (filters/search find nothing, both tabs) · **Show every month** (a figure finds nothing) · **Open reports to validate** (My reports empty, user can validate) · **Show validated reports** (queue empty, validated ones exist). No button when the user can do nothing. |
| Required fields / prefill | Not applicable: the index has no form. |

## Deviations from the plan
1. **Validated months stay in the table by default (last), not hidden.** The plan hid them until the "validated" figure was pressed. Keeping them, sorted last, hides nothing, keeps the "every generated month with its state" test true, and the figure still lists only them.
2. **The LocalizationTest failure that was already on main is fixed** (`lang/ar/proposals.php:967` `n_indicators` plural ranges), as approved.
3. **Empty-state buttons use `tone="primary"`.** The default secondary tone rendered as plain text on the panel.
