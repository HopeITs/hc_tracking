# M-06 · Site-wide simplification pass · L · one page per slice

ClickUp: https://app.clickup.com/t/123jdbau1qp · after M-01…M-04

## Goal
Apply the meeting's simplification rules to every remaining page, one page per run (`/meeting M-06 <page>`):
1. One search and one filter visible; everything else behind "More filters".
2. Plain verbs instead of unclear labels (Details, Pulse, Portfolio…), one term per idea, EN and AR.
3. Complex layouts become tables with fixed, scrollable column names.
4. An empty state shows one button saying the next step.
5. Fewer required fields; prefill program, year and donor where known.

## Sources of truth
- `meeting/README.md` decision 6. Skill `review-page` (follow it per page: scenario first, then phases). `.ai/rules`: `pages.md`, `ui.md`, `views.md`, `views-enums.md`, `desk.md`, the page's own rule file (`.ai/rules/index.md`), `tests.md`.

## Start state
1. `AGENT.md §2`; branch `meeting/M-06-<page>`.
2. The argument names one page. If it is missing, list the candidates (every `resources/views/pages/*/⚡index.blade.php`, ordered by line count) in the report and stop.
3. Write the page's scenario (who, the one question, the 1–3 jobs, click count) before touching code.

## Rules
- Follow `review-page` §3. Never remove a capability a role still needs: a hidden filter stays reachable under "More filters".
- A string change touches `lang/en` and `lang/ar` together; Arabic uses the site's existing vocabulary (قياس, not قراءة).
- Keep page logic and `data-test` hooks; update tests that assert removed UI.

## Build order (TDD)
Update or add the page's Livewire test first (visible controls, More filters content, empty state, required fields), then the views, then a browser check in both languages, both themes, phone.

## Definition of done
- [ ] The page's tests green, `LocalizationTest` green, Pint clean; handoff lists what moved behind More filters and every label renamed.

## Stop and escalate
A filter nobody could reach after the change, or a wording that changes a financial or legal meaning.

## Do not
Redesign pages M-01…M-04 already rebuilt, or touch money-visibility rules.
