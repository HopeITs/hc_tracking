## Rules
**Slice 1**
- The reading is entered on the report line for that indicator and period. It must feed the same figures the indicators page used (achievement vs target, RAG, last measured) so numbers stay equal; assert it in a test with the old computation as the oracle.
- Permissions: the ones that decide today who may log a reading and who may edit a monthly report line. Do not widen.
- Arabic says قياس, never قراءة (`indicators.md`).

**Slice 2**
- Remove both pages from the sidebar; the routes redirect (301) to the logframe page or the active reports page, whichever the old link meant. Delete no model, no policy, no permission, no table.
- Desk panels and notifications that linked to the old pages point to the new places.
- Keep the page tests that still describe live behavior by moving them; delete a test file only with approval.
