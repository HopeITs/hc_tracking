# M-02 · Active Reports: one table for every report type · M

ClickUp: https://app.clickup.com/t/123jdbau1qj

## Goal
One page, one table, listing every report that is still open: monthly reports, donor reports and the existing reports. A "Type" column says which. A user sees at once what needs them.

## Rules
- Active Reports is one Livewire page. Rows come from the three sources through one query layer (a support class returning a common row shape: type, name, program/proposal, period, status, due date, owner, link). Query count is flat (assert it).
- Two tabs at most: "Needs me" and "All". One search and one filter (type) visible; status, program, donor, period behind "More filters".
- Remove the Board and Portfolio views of `reports/index`; the Table/Board/Calendar switch goes away on this page. Keep their routes working (redirect old URLs, including query strings, to the new page).
- A row opens its record with the eye button (`pages.md`). Dates, statuses and words plain, EN and AR.
- Keep each type's own record pages and permissions unchanged.

## Build order (TDD)

## Stop and escalate
A report type whose "open" status is ambiguous, or a permission gap that would show a user reports they cannot open today.

## Do not
Change report workflows, statuses or permissions; delete record pages.
