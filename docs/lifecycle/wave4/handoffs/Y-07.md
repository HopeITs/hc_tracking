## Delivered contracts (exactly as on the branch)
`contracts.md §12.4` carries the `[contract]` text verbatim (first change of the PR).

All four classes are `final`. Each one runs `DB::transaction` → `Gate::authorize('manage', $template)` (`ReportTemplatePolicy::manage`) → `$template->questions()->whereKey($id)->lockForUpdate()->firstOrFail()` (BOLA). None of them writes `narrative_questions`.

- `App\Actions\ReportTemplates\SaveReportTemplateQuestion::handle(ReportTemplate $template, ?int $questionId, array $data, ?string $expectedUpdatedAt = null): ReportTemplateQuestion`, with `@param array{text_ar: string, text_en?: ?string, frequency: string} $data`.
  - A null id creates the question, appended last in its frequency, with `narrative_question_id` null.
  - A changed frequency is refused with `report_templates.question_frequency_locked` (error key `frequency`) when answers exist. Without answers, the question goes last in the new frequency.
  - A stale `expectedUpdatedAt` is refused with `report_templates.stale` (key `question`).
  - An edit that changes nothing writes and records nothing.
- `App\Actions\ReportTemplates\MoveReportTemplateQuestion::handle(ReportTemplate $template, int $questionId, string $direction): void`.
  - `$direction` is `up` | `down`; any other value throws `InvalidArgumentException`.
  - It locks the frequency's rows in ascending id order and renumbers them 1…n. A move past either end does nothing.
- `App\Actions\ReportTemplates\SetReportTemplateQuestionActive::handle(ReportTemplate $template, int $questionId, bool $active): void`. Asking for the state the question already has is refused with `report_templates.stale` (key `question`).
- `App\Actions\ReportTemplates\DeleteReportTemplateQuestion::handle(ReportTemplate $template, int $questionId): void`. Refused with `report_templates.question_has_answers` (key `question`) when any `monthly_report_answers` row points at the question.

## Deviations from contracts.md / the prompt
1. Activity is recorded with `ActivityRecorder::record(..., notify: false)`, not `$template->recordActivity()`. `recordActivity()` has no `notify` argument and fans out notifications, while these keys are activity-only. This is the same pattern as `DeleteDonorReportFile` and `ReportTemplatePrefiller`.
2. A move records no activity: the prompt lists only the four keys.
3. `question_switched` has one sentence for off and on. Separate wording would need a special case in `ActivityPresenter::sentenceKey`.
4. Extra lang key `question_frequency_locked`, for the frequency-locked refusal the prompt describes.
5. Submitted and validated reports read their stored answers (plan Q1, approved).
   - `question_text` is the Arabic text, so an English viewer sees the Arabic question on a locked report.
   - A question that was never answered before submit is no longer listed on the locked report.
6. `tests/Unit/WaveFourProjectsGuardTest.php` was broken on `main`: Unit tests are not bound to `TestCase`, so `base_path()` fails. `base_path()` is replaced with `dirname(__DIR__, 2)`; the allow-list is unchanged.
7. Both slices were done in one session at the developer's request (`AGENT.md §8` says one slice per session).
