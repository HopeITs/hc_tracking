## Delivered contracts
- Added the prompt's approved placement contract to §12.4 and its notification key to §15.2.
- `report_template_placements` stores the proposal and place, decision status, template, actor and timestamp. Existing templates and reports are retained.
- `TemplatePlacementStatus`: pending, joined, created, with English and Arabic labels.
- `JoinReportTemplate::handle(Proposal $proposal, ReportTemplate $template, array $planIndicatorIds, string $expectedStatus = 'pending'): ReportTemplate`.
- `CreateReportTemplateForProposal::handle(Proposal $proposal, ReportPlace $place, string $expectedStatus = 'pending'): ReportTemplate`.
- All placement writers serialize on the program, then proposal, then placement and template. This also serializes first arrivals at a city-wide place, where the nullable center in the database unique index cannot alone prevent duplicates.
- Actions authorize the module permission and the placement's MEAL coverage on the server, then check donor approval, exact place, pending status and selected target ownership.
- An overlapping library indicator always adds the new proposal's pending target line; the monthly builder turns it into a share of the existing monthly line. Unselected extra targets appear as Not reported in this template.
- Prefill retries preserve pending decisions and the joined selection. Selected pending lines still refresh missing fixed denominators when beneficiaries become available; omitted targets are never added. The prefill dry run follows the same rules and counts each shared template once.
- `report_template.placement_pending` notifies the place's responsible MEAL officer, falling back to the MEAL Manager slot. It is sent after commit once, links to the queue, and contains no money.
- Queue: Choose a report, New templates, Lines added. Both decisions require confirmation and name the proposal and place. The Create consequence accounts for places already having more than one template.
- Project tabs now select among their own templates. The queue deep-links to the selected template.
