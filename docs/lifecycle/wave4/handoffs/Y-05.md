**Window (`months()`)**
- An open `to` means this month.
- An open `from` means the earliest report period the other filters select, else January of `to`'s year.
- When `from` is after `to`, it returns `[]`.

**Where each filter reads**
- **Place filters:**
  - on the **template** (`report_templates.city_id/program_id/center_id/city_wide`) for lines, shares and reports;
  - on the target's place columns for targets.
- **Proposal and donor filters:**
  - for lines and shares, through the shares' targets (`plan_indicators.source_id`);
  - for reports, through `proposal_report_template`;
  - never through `project_proposal`.
- Payroll proposals are excluded. No money column is selected.

**D-90 shared target (`all_centers`)**
- It gets one row per place of a template that holds it, with `shared_centers = N`.
- Its value is counted **once** in every library or total figure.
- A ratio is pooled per center: one `PlanIndicator::pooledRatio()` term per template, the same rule as `MonthlyReportSharedTargets`.

**Two templates at one place** are one row:
- counts are summed;
- cumulative counts take the latest figure per template, then sum;
- ratios are pooled.

### Page `reports/⚡monthly-matrix`
**`#[Url]` properties**
- `proposal`, `donor`, `center`, `city`, `program`, `indicator`, `pillar`
- `from`, `to` (`Y-m`)
- `mine`, `view`, `tab`, `pwd`
- `year`, kept only so old links can be translated.

**`center` values**
- `c{hrCenterId}`
- `field-{cityId}` (D-88)
- `unset` (D-82)

**`mount()`**
- A bare-digits `center` is a legacy project id. It becomes the project's place through `placeOfProject()`.
- `?year=` becomes Jan–Dec of that calendar year, or grant year N of the single filtered proposal.
- With no filter set, the window is January → this month.

**Computeds**
- `extractionFilter`, `months`, `matrix`, `pagedRows`
- `centerOptions` (`list<array{value, label}>`) and `programOptions`
- `hasWholeGrant`, `emptyReason`. `emptyReason` returns the **name** of the filter that emptied the result, in the order filters were applied (`#[Locked] $filterOrder`).

**Actions:** `thisYear()`, `wholeGrant()`, `clearFilters()`.

**Behaviour**
- From > To shows the field error `from` and an empty matrix.
- Picking a center sets its city. Changing the city clears a center from another city.

**Matrix row keys:** `key, place_key, place_keys, center, city, shared_centers, source_windows, library_id, code, name_en, name_ar, is_active, measure, unit, is_cumulative, is_disaggregated, attribution, is_group, centers_count, breakdown, breakdown_kind, breakdown_raw, denominator_basis, sources, target_ids, target, cells, total, excluded, achieved`.
- Removed: `project_*` and `pooled_ids`.
- Center row key: `row-{placeKey}-{library}`; donor row key: `target-{plan}`.
- `centers_count` counts distinct places.
